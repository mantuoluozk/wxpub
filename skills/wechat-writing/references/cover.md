# 公众号封面

用户要做新封面时，默认用当前环境可用的图像生成工具直接生成整张成图。WorkBuddy 可用时调用它的图片生成能力；别的宿主调用其已配置的生图工具。用户给了定稿封面就直接采用；已有封面且用户只要预览或推草稿时继续使用它。

1. 从稿件里提取一个能画出来的核心对象、动作或结果。教程可以演示工具或操作，复盘可以呈现现场或关键变化，新闻可以用主角产品和更新点构图。先读用户给的参考图；项目有 `风格参考/` 时，按文件名或索引挑一张同题材的旧封面。缺少样例时按文章内容定视觉。
2. 要求模型输出 2.35:1 横版，主体和必要文字放在中心区域，预留左右裁切空间。默认优先用画面讲清主题；上封面文字时，让模型把用户确认的短标题一并生成，确保逐字准确。少用视觉元素，保持缩略图清楚。参考用户提供的产品图或截图时，避免让模型伪造界面中的数据和操作结果。
3. 检查成图和缩略图。文字有错时用生图工具修正，或改用无字版。图像工具不支持目标比例时，可先让模型生成最接近的宽图，再裁切到 1280×544；裁切会损失主体时修改构图重新生成。
4. 将选中的实际图片保存为文章目录下的 `cover.png`，在 Markdown frontmatter 写 `cover: cover.png`。预览和草稿推送都用同一个文件；用户明确要求重做时才替换已有封面。

当前环境没有生图工具或无法取得实际图片时，告诉用户，并用 `wxpub cover article.md -o cover.png` 生成排版版封面供预览。用户要手动生图时，交付短提示词与目标比例。

参考花叔的 [公众号配图](https://github.com/alchaincyf/huashu-skills/tree/master/huashu-wechat-image) 和 [参考图用法](https://github.com/alchaincyf/huashu-gpt-image/blob/master/SKILL.md)。
