# 手绘封面

公众号新封面固定使用暖米白纸纹、石墨线稿和钴蓝为主的手绘插画，可以用少量朱红点出变化。标题用深墨色粗体，靠左排，图像主体在右半边，左右两侧留给平台裁切。用户提供定稿就沿用；只需预览或推草稿时沿用已有封面。

## 生成无字背景

根据文章选一个能画出来的对象、动作或结果，同一套配色下换题材。例如讲排队就画请求卡片依次进入芯片。用 WorkBuddy 或当前会话的图片生成工具画背景，参考 [手绘底图](../assets/cover-style.jpg) 的纸纹、线稿与配色。保留画面的安静区域和可辨认的单一主体。

可把这段作为生图说明，替换括号里的内容：

> 手绘科技编辑插画，（具体主体与动作）。暖米白纸纹、石墨线稿、钴蓝主体、少量朱红。主体集中在横向约 58%–76% 的区域，左侧标题区（横向 22%–56%、纵向 20%–54%）保留连续浅色，边缘留裁切空间。2.35:1 宽幅。画面里不出现文字、数字、Logo 或水印。

默认交付 `1280×544` 的公众号封面。给 PPT 做同系列封面时改成 `16:9` 构图，沿用配色、左字右图和手绘质感。在 PPT 里用独立文本框叠标题，方便修改；只需封面图文件时可以用下面脚本的 `--format ppt`。

## 叠标题并交付

把实际生成的无字图保存到文章目录，例如 `cover-background.png`。标题单独叠加，使用用户给定的封面标题，或使用文章标题，过长时先拟一个原意一致的短标题。保持字色和位置统一，通常一到两行。用 Skill 自带脚本，路径相对 Skill 目录，输入输出路径换成实际路径：

```bash
python scripts/compose_cover.py cover-background.png --title "首字为什么慢" -o cover.png
```

脚本依赖 Pillow。需要装依赖时用 `python -m pip install Pillow`。有统一品牌字体时用 `--font` 指定中文粗体；系统默认用微软雅黑粗体、思源黑体或苹方。用户要无字封面时直接用底图。检查成图与缩略图，确认标题无遮挡后在正文 frontmatter 写 `cover: cover.png`。预览和推草稿时明确使用同一张实际图片。

当前会话没有生图工具或没有返回可用图片时，说明卡点，交付生图提示词，等用户提供背景或选择其他方式。只有用户明确选择模板时，才使用 `wxpub cover` 或 `wxpub publish` 的自动模板。

方法参考花叔的 [公众号配图](https://github.com/alchaincyf/huashu-skills/tree/master/huashu-wechat-image) 和 [参考图用法](https://github.com/alchaincyf/huashu-gpt-image/blob/master/SKILL.md)。
