# 公众号封面

用户说“生成封面”“做一张封面”“重新做封面”时，先读文章或主题，再调用当前会话真实可用的图像生成工具。在 WorkBuddy 优先使用它的图片生成能力。用户给了定稿封面就直接采用；已有封面且用户只要预览或推草稿时沿用它。

1. 给模型一个具体的画面：画什么主体、主体在做什么、这个动作怎样说明文章主题。教程可用真实工具或操作画面，复盘可画关键过程，资讯可抓住一个变化做概念插画。用户给了参考图，或指定了项目的 `风格参考/`，可取一张同题材参考构图和视觉调性。
2. 要求 2.35:1 横版，把主体放在中心区域，留出左右裁切空间。默认以有具体主体的无字插画或有辨识度的场景为主。用户要求有字时，让模型将确定的短标题画进画面，文字配合主体构图。避免只有标题、纯色背景或空泛装饰的封面。
3. 打开实际成图检查主体、裁切后的缩略图和文字。有错字就重新生成，或在用户接受无字封面时出无字版。工具没有目标比例时，可用接近的宽幅图裁切至 1280×544；主体被裁掉就调整构图重做。
4. 将选中的实际图片写入文章目录（例如 `cover.png`），更新 frontmatter 的 `cover`。预览和推草稿时核对路径及文件存在，必要时为 `wxpub publish` 显式传同一张图的 `--cover`。只在用户要求重做封面时替换既有文件。

当前会话没有可用的图像生成工具、调用失败，或未返回可用图片时，说明停在哪一步，交付可复制的生图提示词和比例，等用户提供图片或选择其他方式。只有用户明确选择模板封面时，才执行 `wxpub cover` 或使用 `wxpub publish` 的自动模板。提示词、排版模板和真实生成的图片按实际产物描述。
